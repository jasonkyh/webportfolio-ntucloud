02 — Core Service Offerings

Same building blocks, different philosophies

Compute, storage, and AI are table stakes for all three providers — the differentiation shows up in how each is engineered. Toggle between categories to compare.

AWS

EC2 + EKS/ECS + Lambda

Widest VM family spread (general/compute/memory/storage-optimised, accelerated). Mature container and serverless stack suited for everything from HPC to microservices.

Azure

Virtual Machines + AKS + Functions

Windows-optimised VMs and Azure Boost performance tuning. Arc-enabled AKS bridges on-prem and cloud, with native GitHub CI/CD.

GCP

Compute Engine + GKE + Cloud Run

Custom machine types, preemptible pricing, and live migration. As the Kubernetes originator, GKE Autopilot leads on container automation.

AWS wins on breadth, Azure on hybrid/enterprise alignment, GCP on infrastructure flexibility and Kubernetes-native tooling.

AWS

S3 · EBS · EFS · RDS/Aurora

Durable object storage, high-performance block storage for critical workloads, and Aurora for scalable relational databases with replication.

Azure

Blob · Managed Disks · Azure Files · SQL DB

Tiered storage with fine-grained access control, disks integrated directly with VMs, and SQL Database built for hybrid, Windows-centric environments.

GCP

Cloud Storage · Persistent Disk · Spanner/Cloud SQL

Multi-regional storage built for global consistency, and Spanner — a horizontally-scalable relational database rare among the three.

GCP's Spanner is the standout: globally consistent relational data at scale, a genuinely hard problem the other two don't solve the same way.

AWS

SageMaker · Bedrock

End-to-end ML lifecycle tooling plus Rekognition, Comprehend, Polly for rapid task implementation. Bedrock offers multi-model access without infra management.

Azure

Azure ML · Azure OpenAI Service

MLOps pipelines and model registry, paired with Azure AI Services that lower the barrier for non-technical teams.

GCP

Vertex AI · Gemini · BigQuery

Unified workflow with direct access to Gemini foundation models, AutoML, and deep integration with BigQuery for analytics-driven AI.

This is GCP's home turf — the tightest link between data warehousing (BigQuery) and model development of the three platforms.

05 — Technology & Innovation

Where the next decade of differentiation gets built

Beyond core infrastructure, all three are racing across three frontiers: AI-native operations, quantum computing, and the edge.

AI-Powered Cloud Operations

Generative AI embedded into the console itself
  • AWS — Amazon Q generates IaC, explains errors, and automates troubleshooting across console, CLI and IDE.
  • Azure — Copilot for Azure produces deployment scripts (CLI/PowerShell/Terraform) and monitors cost and security posture.
  • GCP — Gemini Cloud Assist & Code Assist pair natural-language design with contextual, IDE-native coding help.

Quantum Computing

Experimental, but strategically staked out
  • AWS Braket — multi-hardware access; used by BMW for material deformation and quality-assessment simulation.
  • Azure Quantum — enterprise-integration play, benchmarking portfolio and fleet optimisation with KPMG.
  • GCP Willow chip — a benchmark in minutes that would take a classical supercomputer 10 septillion years.

Edge Computing

Bringing compute to where data is created
  • AWS Wavelength — cut Verizon/NHL video delivery latency from seconds to milliseconds.
  • Azure Edge Zones — piloted beyond-visual-line-of-sight autonomous drone control with AT&T and EVA over 5G.
  • Google Distributed Cloud Edge — powers Kroger's frictionless checkout and real-time inventory monitoring.
06 — Economics & Strategy

Pricing as a lever, not just a price tag

All three run pay-as-you-go at the core, but the discount architecture around it reveals who they're really optimising for.

AWS

  1. Savings Plans — flexible commitment by spend, not instance type.
  2. Reserved Instances — 1–3yr terms, up to 72% off + zone capacity reservation.
  3. Spot Instances — up to 90% off unused capacity, short-term.
→ Developer-centric flexibility across services & regions.

Azure

  1. Hybrid Benefit — reuse existing Windows/SQL licences for savings.
  2. Reserved VMs — up to 72% off, stackable to 80% with Hybrid Benefit.
  3. Spot VMs — up to 90% off, mirroring AWS's model.
→ Outsized value if you're already a Microsoft shop.

GCP

  1. Sustained Use Discounts — automatic, no commitment required.
  2. Committed Use Discounts — 1–3yr terms, up to 79% off.
  3. Preemptible VMs — up to 91% off, the deepest of the three.
→ Rewards steady analytics/data workloads by default.

07 — Sustainability

Data centres are projected to hit 20% of global electricity demand

Left unmanaged, hyperscale growth accelerates climate impact and drives up cooling costs. Each provider is racing toward a different definition of "clean."

AWS
Net-zero by 2040

Water-positive by 2030. Reengineered power distribution and liquid cooling lifted efficiency — global PUE of 1.15 in 2023, with the best site at 1.04.

PUE 1.15 avg (1.00 = perfect efficiency)

Microsoft / Azure
Carbon-negative by 2030

Water-positive and zero-waste by the same year. Wind-linked batteries in Ireland, surplus heat warming 6,000 Danish homes, and free-air cooling in Sweden cutting energy 30% and water 90%.

GCP
Net-zero by 2030

The most aggressive target — net-zero across operations and the full supply chain, powered by 24/7 carbon-free energy via co-located renewable projects with Intersect Power.

08 — Outlook

No single winner — a diversifying oligopoly

Agentic AI is the next inflection point

Amazon Bedrock & Q, Azure OpenAI Service, and Gemini/Vertex AI are all converging toward systems that can autonomously plan, reason, and execute — not just respond. This is where the next wave of platform differentiation will play out.

Rather than a single winner, expect continued divergence along each provider's proven strengths: AWS on breadth and developer reach, Azure on regulated-enterprise compliance, GCP on data-driven, analytics-heavy innovation.

◆ Intelligence — agentic AI & foundation models
◆ Sustainability — 24/7 carbon-free operations
◆ Automation — AI-native cloud operations
